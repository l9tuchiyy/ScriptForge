# ScriptForge

Коллекция полезных Python-скриптов, написанных во время обучения backend-разработке.

## Скрипты

### 🌤 Weather Guardian
Получает погоду нескольких городов через OpenWeather API и сортирует города по температуре.

### 💬 Random Quote
Получает случайную цитату известного человека и позволяет сохранить понравившиеся цитаты.

### 👤 GitHub Profile Viewer
Получает информацию о пользователе GitHub по логину: имя, количество репозиториев, подписчиков и дату регистрации.

## Используемые технологии
* Python 3
* Requests
* JSON
* Git
